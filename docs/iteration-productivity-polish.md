# TraceChat 产品迭代说明：会话管理与输入效率

本轮迭代延续 `product-iteration-docs` 分支，以“高频使用效率”和“会话规模增长后的可管理性”为主线，按特性拆分为独立提交。

## 新增特性

### 1. 侧边栏内联重命名会话

用户现在可以在左侧会话列表直接点击“编辑”修改会话标题。后端新增会话更新接口，前端保存后同步刷新列表状态。

价值：

1. 用户可以把“新对话”整理成可识别的任务名称。
2. 多会话工作时更容易回到正确上下文。
3. 会话标题写入后端持久化，不只是前端临时状态。

### 2. 侧边栏会话搜索

会话列表新增搜索框，支持按会话标题过滤。

价值：

1. 会话数量增加后仍能快速定位。
2. 搜索在本地完成，响应快，不增加后端压力。
3. 空结果时给出明确状态提示。

### 3. 支线库状态计数

支线库状态筛选按钮现在显示各状态数量，并改为一次加载当前会话全部支线后在前端筛选。

价值：

1. 用户可以快速判断当前会话有多少活跃、保存、回填或归档支线。
2. 切换筛选条件不再反复请求后端。
3. 支线库更像一个可管理的信息资产面板。

### 4. 主线和支线消息一键复制

主线消息和支线消息现在都提供“复制”操作，复制成功后会短暂显示“已复制”。

价值：

1. 方便把局部结论带到外部文档、Issue、PR 或笔记。
2. 支线推导结果可以被更轻量地复用。
3. 不需要手动选择气泡内容，减少误选和漏选。

### 5. Ctrl+Enter 发送

主线和支线输入框改为 `Ctrl+Enter` 或 `Cmd+Enter` 发送，普通 Enter 保留为换行。

价值：

1. 更适合输入较长提示词、分点问题和多段上下文。
2. 减少误触发送。
3. 同时兼容 Windows/Linux 的 Ctrl 和 macOS 的 Cmd。
