# TraceChat 产品迭代说明：更安全的支线引用流程

本轮优化聚焦主线输入前的防误操作，降低用户把错误支线、无摘要支线或重复上下文带入主线的概率。

## 新增特性

1. 主线引用栏展示已引用支线数量。
2. 每个引用项展示支线标题和摘要预览。
3. 引用栏支持逐个移除和一键清空。
4. 没有摘要的支线不可直接引用，并提示先生成摘要。
5. 主线和支线发送按钮显示更明确的禁用原因。
6. 流式生成中输入框仍可保留草稿，但发送按钮会进入“生成中”状态，避免重复发送。

## 用户价值

1. 用户能在发送前确认本轮主线会读取哪些支线摘要。
2. 支线必须先摘要再引用，保持“摘要进入主线、完整支线不自动污染主线”的产品规则。
3. 多引用场景下可以快速清理上下文，减少误带旧引用。
