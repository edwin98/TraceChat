# TraceChat 产品迭代说明：支线找回与来源导航

本轮优化让支线库从“列表”进一步变成可操作的支线工作台，重点解决历史支线找回和来源定位成本。

## 新增特性

1. 支线库支持按最近更新、最近创建、标题排序。
2. 支线库支持按“有摘要 / 无摘要”筛选。
3. 支线卡片新增“来源”动作，可直接滚动到来源主线消息。
4. 支线详情来源卡新增“打开来源”动作。
5. 主线消息增加稳定锚点，被定位时会短暂高亮 1.5 秒。

## 用户价值

1. 支线数量增加后，可以按不同工作方式找回内容。
2. 从支线结论回到主线语境更快，减少上下文迷失。
3. 支线来源关系更明确，符合 TraceChat “支线不脱离主线来源”的产品心智。
